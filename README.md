# Kazi Haque — Executive Portfolio & Advisory Showcase

A premium, interactive, and fully responsive single-page portfolio website designed for **Kazi Haque**, an AI Product Leader, SaaS Co-Founder, and Technical Advisor. 

This website is custom-engineered to showcase founder achievements (securing seed capital, scaling SaaS ARR, launching systems for Fortune 500 clients) and position him for high-level enterprise consultancy roles.

👉 **Live Site**: [https://kazi92.github.io/portfolio/](https://kazi92.github.io/portfolio/)

---

## Key Features

- **Obsidian & Gold Executive Aesthetics**: Default premium styling utilizing modern serif typography (`Cormorant Garamond`) and deep slate backdrops accented with golden glows.
- **Global Light/Dark Theme Switcher**: Full support for shifting between clean light surfaces and obsidian dark modes.
- **Dynamic Accent Selector**: Toggleable color presets changing glows and highlight details (*Obsidian Gold*, *SaaS Emerald*, and *Steel Digital*).
- **Core Metrics Banner**: Displays high-impact stats ($500K Seed, 10+ Fortune 500 Deploys, $500K+ Annual SaaS ARR, 100K+ Developers Trained) right below the fold.
- **Interactivity Engine**:
  - Floating custom cursor follower that scales on hover items.
  - High-performance HTML5 Canvas background particle system responding to mouse coordinates.
  - 3D parallax hover tilt effect on visual elements.
  - Typewriter animation detailing core expertise.
- **Advisory Services & Ventures**: Custom-designed decks showcasing fractional CPO services, DevRel advisory details, and shipped product dashboards (*Callchimp.ai*, *Kernopy.com*, *Contatrack.ai*).
- **Ecosystem Advocacy Section**: Dedicated badges and timelines displaying community leadership (GDG India, Intel, Dify.ai, DigitalOcean) and academic speaking history (IITs, ISI Kolkata).

## Local Development & Preview

To preview the website locally on your computer:

1. Clone or download the repository files.
2. Open your terminal in the directory and run a local server:
   ```bash
   python3 -m http.server 8080
   ```
3. Open [http://localhost:8080](http://localhost:8080) in your web browser.
